# System Flow

1. User opens EduGenie.
2. User selects a learning mode.
3. User enters an educational topic.
4. The application receives the topic.
5. The Python application creates an appropriate prompt.
6. The prompt is sent to the Google Gemini API.
7. Gemini generates educational content.
8. EduGenie receives the generated response.
9. The response is displayed in the Streamlit interface.
10. The user can continue learning or select another learning mode.
