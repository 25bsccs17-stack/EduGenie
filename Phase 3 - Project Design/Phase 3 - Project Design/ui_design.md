# UI Design

## Main Screen

The EduGenie main screen contains:

- EduGenie title
- Project description
- Learning mode selection
- Topic input field
- Generate button
- AI-generated result section

## Learning Modes

EduGenie provides five learning modes:

1. Learn
2. Exam Preparation
3. Quiz Generator
4. Real-Life Examples
5. Study Planner

## User Interaction

The student selects a learning mode, enters a topic, and clicks the Generate button.

## Output

The AI-generated educational content is displayed below the input section in an easy-to-read format.

## Interface Technology

The user interface is developed using Streamlit and Python.
