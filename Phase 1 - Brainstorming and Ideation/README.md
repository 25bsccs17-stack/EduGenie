# Phase 1 - Brainstorming and Ideation

## Project Name
EduGenie – Google Gemini Powered Learning Assistant

## Project Idea
EduGenie is a Gemini-powered personal learning assistant designed to help students learn topics, prepare for exams, generate quizzes, understand real-life examples, and create personalized study plans.

## Problem Statement
Students often face difficulties understanding complex topics, preparing for examinations, practicing questions, and managing their study time effectively.

## Proposed Solution
EduGenie uses Google Gemini to provide AI-powered educational assistance through different learning modes.

## Target Users
- School students
- College students
- Students preparing for examinations

## Main Features
1. Topic learning
2. Exam preparation
3. Quiz generation
4. Real-life examples
5. Study planning
6. AI-powered educational responses

## Technologies
- Python
- Streamlit
- Google Gemini API
- Visual Studio Code
