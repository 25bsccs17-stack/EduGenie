# Phase 2 - Requirement Analysis

## Project Name
EduGenie – Google Gemini Powered Learning Assistant

## Functional Requirements

The system should allow users to:

1. Enter an educational topic.
2. Select a learning mode.
3. Generate AI-powered explanations.
4. Generate exam preparation material.
5. Generate multiple-choice quizzes.
6. Generate real-life examples.
7. Create personalized study plans.
8. View the generated educational content.

## User Requirements

The application should provide a simple and user-friendly interface so that students can easily enter a topic, select a learning mode, and generate educational content.

## AI Requirement

The application should use the Google Gemini API to generate educational responses based on the student's selected topic and learning mode.

## Security Requirement

The Gemini API key must be stored securely in an environment file and must not be exposed in the source code or uploaded to GitHub.
