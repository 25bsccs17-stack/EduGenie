# Non-Functional Requirements

## Usability
The application should have a simple and user-friendly interface that students can understand easily.

## Performance
The application should generate AI responses within a reasonable amount of time.

## Security
The Gemini API key must be stored securely in an environment file and must not be hard-coded or uploaded to GitHub.

## Reliability
The application should handle API errors gracefully and display a useful error message to the user.

## Maintainability
The project should use clear code, organized documentation, and a structured project folder.

## Scalability
The application should be designed so that additional learning features can be added in the future.
