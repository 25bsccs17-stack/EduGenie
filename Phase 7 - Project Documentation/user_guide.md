# EduGenie – User Guide

## 1. Starting EduGenie

Open the project in Visual Studio Code.

Open the terminal and run:

streamlit run app.py

The EduGenie application will open in a web browser.

## 2. Selecting a Learning Mode

Use the **Learning Modes** menu on the left side of the application.

The available modes are:

- Learn
- Exam Preparation
- Quiz Generator
- Real-Life Examples
- Study Planner

## 3. Learn Mode

Select **Learn**.

Enter a topic such as:

Python Functions

Click **Generate**.

EduGenie provides a simple explanation, important concepts, examples, and revision points.

## 4. Exam Preparation

Select **Exam Preparation**.

Enter the required topic and click **Generate**.

EduGenie generates exam-oriented study material including short and long answers.

## 5. Quiz Generator

Select **Quiz Generator**.

Enter a topic and click **Generate**.

EduGenie generates multiple-choice questions with answers and explanations.

## 6. Real-Life Examples

Select **Real-Life Examples**.

Enter a topic and click **Generate**.

EduGenie explains the topic using practical examples and analogies.

## 7. Study Planner

Select **Study Planner**.

Enter a topic.

Choose:

- Number of study days
- Study hours per day

Click **Generate**.

EduGenie creates a personalized study plan.

## 8. Empty Topic

If the topic field is empty and the user clicks **Generate**, EduGenie displays a warning asking the user to enter a topic.

## 9. API Errors

If the Gemini API reaches its usage limit or is temporarily unavailable, EduGenie displays an error message.

The user can wait and try again later.
