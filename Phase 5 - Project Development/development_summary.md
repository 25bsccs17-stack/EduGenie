# Phase 5 - Project Development

## Project Name
EduGenie – Google Gemini Powered Learning Assistant

## Development Summary

EduGenie was developed using Python, Streamlit, and the Google Gemini API.

The application provides five learning modes:

1. Learn
2. Exam Preparation
3. Quiz Generator
4. Real-Life Examples
5. Study Planner

## Development Process

1. Created the Python project environment.
2. Installed the required libraries.
3. Configured the Gemini API securely using an environment file.
4. Developed the Streamlit user interface.
5. Implemented the five learning modes.
6. Connected the application with Google Gemini.
7. Added error handling for API failures.
8. Tested all major features.

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- google-genai
- python-dotenv
- VS Code

## Security

The Gemini API key is stored in a `.env` file and is not included in the project source code.

## Development Status

The main EduGenie application has been successfully developed and tested.
