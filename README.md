 # 🎓 EduGenie

## AI-Powered Educational Platform

EduGenie is an AI-powered educational platform designed to provide personalized and interactive learning support for students. It uses Google Gemini to generate educational content based on the learner's selected topic and requirements.

## ✨ Key Features

### 📚 Learn Mode
Provides clear and structured explanations of academic topics to help students understand concepts effectively.

### 📝 Exam Preparation
Generates exam-oriented content, including **2-mark, 5-mark, and 10-mark answers**, helping students prepare according to different question formats.

### 🧠 Quiz Generator
Creates topic-based multiple-choice quizzes with answers and explanations to help students assess and reinforce their understanding.

### 🌍 Real-Life Examples
Connects academic concepts with practical, real-world examples to make learning more meaningful and relatable.

### 📅 Study Planner
Creates personalized study schedules based on the number of study days and the amount of study time available each day.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## 🎯 Objective

The objective of EduGenie is to bring learning, examination preparation, assessment, practical understanding, and personalized study planning together in a single AI-powered educational platform.
